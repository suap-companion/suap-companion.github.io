# suap-companion.github.io

Site do **suap-companion** (https://suap-companion.github.io/): página de produto do
[chamados](https://github.com/suap-companion/chamados), com o app Android (organizar a vida) e o CLI
(automação com IA), links de download da release mais recente e o guia de uso.

Site estático (sem build): `index.html`, `assets/style.css`, `assets/app.js`. Publicado pelo GitHub
Pages a partir da branch `main`. Para ver localmente: `python -m http.server` e abrir
http://localhost:8000/.

A fonte **Rawline** (SIL OFL 1.1) fica em `assets/fonts/` com a licença; as capturas de tela são do app.
Este não é um projeto oficial do IFRN nem do SUAP.
